What the system does

Living-room TV client (Flutter, 32-bit ARM)

  • Home: featured hero with Resume/Details, Continue Watching (poster, progress, backdrop), Recently Added, Upcoming; D-pad driven with visible focus.
  • Movies / Series: poster grids, details, season/episode lists, watched badges, context menus (open, mark watched/unwatched), series-level bulk actions.
  • Playback: resume (movie + episode), HUD auto-hide, Back toggles HUD (not exit), accelerated seeking, FF/REW media keys, bilingual subtitles, up-next countdown and autoplay, audio/subtitle pickers, subtitle timing nudge.
  • Music: artists/albums/songs/recently-added, album view with Play all, queue, now-playing bar, resume across restarts, background audio, media keys.
  • YouTube: subscription videos browsable and playable; Adult: separate visible section with PIN-gated entry; Search, Settings, client-error telemetry.

Web SPA

  • Dashboard (continue watching, recently added, task/system status), Movies, TV Shows, Collections, Calendar, Search, Settings, Events, Backup, Statistics.
  • Wanted list grouped by viewing priority with a subtitle-coverage summary (e.g. “34 high-priority · 9 EN+ZH · 21 Chinese only · 4 without Chinese”).
  • Watched chips on movie and series rows; imports/import wizard, interactive search, quality profiles, indexers, download client settings.
  • YouTube and Adult sections; client error triage surfaced from the TV.

Server engine (single Bun/Node daemon + SQLite)

  • Libraries: Movies, Series/Episodes, Adult (197 items), YouTube (290+ available), Music (217 tracks / 12 artists / 16 albums) — one database, one state model.
  • Scheduler: RSS sync, import lists, wanted search, subtitle wanted (priority-ordered), bilingual EN+ZH cycle, subtitle timing sync, library scan, episode thumbnails, adult thumbnails, YouTube poll/download/retention, folder import, auto-update, music nightly receipt, staging tidy, subtitle coverage snapshot + priority wanted queue.
  • Playback API: manifests with resume/stream/subtitles, progress upserts with watched-state and regression guard, watched marking for movie/episode/series, up-next queue.
  • Subtitles: health audit, EN+ZH coverage for recent/in-progress items, viewing-priority classifier, OpenCC normaliser (dry-run by default, dated backups), ffsubsync alignment, bilingual merge/translation with per-item receipts.
  • Automation & operations: watchdog + expectations, local-first alerts with retry, quarantine engine with hash verification, weekly backups, graceful shutdown, stale-claim recovery, client error intake, task history.

DeepSeek Harness (the brain)

  • Scheduled agent runs: daily media orchestrator 03:00, weekly database backup (Sundays 04:30), TV-client error triage every 30 minutes.
  • dsh-media-automation plugin: frozen ledger schema, heartbeat, alerts, quarantine and watchdog tools, alert delivery with webhook transport; installed via a repo symlink, never a copy.
  • Measure guard: plan/task discipline enforced, every task traceable to a commit SHA with a git note.

Known open items owner-gated or measured ceiling

  • Subtitle acquisition: all subtitle providers are disabled (no API key) — fetching new Chinese subtitles is owner-gated; 169 traditional files and 762 Chinese-only variants are listed and queued.
  • Traditional → simplified conversion: tool ready (dry-run over the library, 169 files identified); needs the owner’s convert-with-backup vs re-download decision.
  • Harness cutover: linking the automation plugin into the live profile and the reboot proof restart this agent session, so both wait for an owner-approved window.
  • Weekly music ingest: pipeline + receipts exist; needs a curated source list from the owner.
  • YouTube backlog: ~5 videos/hour ceiling because this laptop has no working hardware encoder (VAAPI/QSV fail); 1080p60 sources need a real encode. Remux path is used when possible.
  • TMDB API key: invalid, so artwork backfill cannot run (operator action).
