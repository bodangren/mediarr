The principle

interface stability decides the substrate

The fragile part was never “scripts” — it was our own parsers of rendered web UIs. An LLM driving a real browser adapts to a changed page and can say what broke; a selector script cannot. But an API or a maintained CLI never had that problem in the first place.

New media domains

three scoped tracks, one automation layer

Owner feedback turned these from “fold it in” into real product work. Each is its own track; the daily/weekly agent runs drive them through the same receipt-and-ledger mechanism, and skip a domain cleanly until it exists.

feature_adult_library_20261107

Adult — a separate library

Own root and a clearly reachable section (not mixed into Movies). The weekly agent browses sources; pruning goes through the quarantine engine instead of raw SQL. Existing 4TB/Porn imports unchanged.

feature_youtube_library_20261107

YouTube — subscribable series

Subscribe to a channel/playlist; yt-dlp pulls new entries, deduped by video id. A watched episode is retired after ~7 days (quarantine → delete). Browsable as a series, D-pad navigable.

feature_music_library_20261107

Music — iTunes-style, from YouTube

Artist/album/track domain; agent picks YouTube tracks, yt-dlp pulls audio (m4a/AAC 256k, mp3 fallback), beets/MusicBrainz tags and files it, and the Flutter player gets a full iTunes-style layout — sidebar, album grid, track list, now-playing bar — fully D-pad navigable.

No silent failures

every agent run is observable

Hermes used the model and could not tell you when it failed. v3 uses the model and can tell you exactly what broke, because the run itself is instrumented.

1

Deliver

Schedule fires; plugin records the occurrence key.

2

Work

Browser tools on web surfaces, shell for maintained CLIs, Mediarr API to act.

3

Diagnose

The agent reports the cause: DOM change, login, VPN, tool error.

4

Record

Receipt + ledger row; plugin reads the turn outcome.

5

Retry / alert

Transient → ≤2 retries. Persistent → webhook alert. No silence.

“Auto-fix” policy: browser work self-adapts; maintained tools are updated, not patched by us; there is no graveyard of selectors to repair. No silent failure is the invariant — every expected run ends in a receipt, a retry, or an alert.

Guardrails & risks

what could bite
Agent runs depend on the provider. That is the accepted trade for adaptation: a provider outage delays the daily/weekly run and alerts; it never silently falls back to a scraper. API-shaped hourly/daily work keeps running regardless.
The browser bridge is now a dependency. Chrome + extension + the bridge's WebSocket + the VPN profile must be up. It is supervised, probed before runs, and a dead bridge is an alert — not a hang.
Retention deletes media. YouTube watched+7d and prune candidates go through quarantine: manifest, restore window, safety rails, byte cap, dry-run week. No manifest, no deletion.
Full-access host. DSH_PERMISSION_MODE=danger-full-access on a trusted single-user LAN; required because scheduled turns cannot answer approvals. Documented and reversible.
No DOM scrapers, by policy. If a site breaks, the browser agent adapts; if a maintained CLI breaks, update it and alert. We do not maintain selector graveyards again.
Domains are product tracks. This migration track builds the automation around them and can ship P0–P3 first; the agent skips absent domains and says so in the receipt.
