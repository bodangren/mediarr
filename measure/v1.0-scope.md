# Mediarr v1.0 Scope Checklist

> Ratified per the 2026-06-07 direction & scope review. Each capability listed below represents a
> must-ship deliverable for v1.0. Unmet items are either in-flight feature tracks or consciously
> deferred to post-v1.0.

## Capabilities

### Server Domains (monolith backend)

- [x] Integrated Torrent Engine (WebTorrent) — torrent lifecycle, seeding protector, queue operations, activity SSE
- [x] Unified Indexer Management — Torznab, Newznab, Cardigann runtime, catalog auto-discovery, LAN discovery
- [x] TV Shows Management — series library, episode tracking, monitoring, automated wanted search, file organization
- [x] Movies Management — movie library, interactive search/grab, wanted list, import pipeline, file organization
- [x] Subtitle Management — inventory indexing, subtitle search/download/delete, variant subtitle services
- [x] Automation Pipeline — RSS sync, wanted search, library scan schedulers with configurable intervals
- [x] Custom Format Scoring Engine — custom format conditions, unified scoring, release evaluation
- [x] Notification Transport Layer — webhook, Discord, Telegram, Gotify, email dispatchers
- [x] Real Auto-Update System — release check, download, install, daily scheduler
- [x] Setup Wizard & Smart Defaults — first-run detection, 5-step wizard, zero-config mode, idempotent defaults
- [x] Streaming Server & Discovery — 4K/HDR playback, mDNS discovery, SSE real-time updates
- [x] Library Statistics & Analytics — dashboard composition charts, download metrics, system health
- [ ] Indexer Health Monitoring & Auto-Disable — cut to post-v1.0; deferred per 2026-06-07 scope review

### SPA Workflows (React frontend)

- [x] Dashboard & Library Browsing — movies/tv tabs, sort controls, poster grid
- [x] Media Detail Pages — movie detail, series detail with episodes, cast cards, streaming badges
- [x] Interactive Search & Grab — manual search, release selection, grab with scoring breakdown
- [x] Activity & Queue Monitoring — torrent progress, mass actions, SSE live updates
- [x] Settings (indexers, download clients, quality profiles, subtitles, general)
- [x] Wanted List Dashboard — missing movies/episodes tabs, search, monitored toggle, pagination
- [x] Custom Format Editor & Live Tester — create/edit/clone/test custom format conditions
- [x] Release Scoring Breakdown Panel — score composition, factor weights, injected into search modals
- [x] System Events Log — filterable event history
- [x] Statistics & Analytics Dashboard — library composition, download metrics, health indicators
- [ ] Scheduler & Automation Dashboard — SPA settings page for configuring/monitoring RSS sync, wanted search, and library scan schedules (in-flight: feature_scheduler_automation_dashboard)

### Flutter Client Screens (cross-platform)

- [x] Home Screen — Continue Watching, Recently Added, Upcoming sections
- [x] Library Browsing — Movies/TV tabs, sort controls, getLibrary integration
- [x] Search & Add Media — poster grid, SearchResultDetailSheet with releases/grab/add-to-library
- [x] Activity & Queue — torrent management, SSE real-time updates
- [x] Calendar — monthly grid, dot indicators, day detail sheet
- [x] Subtitle Management — search, download, quality upgrade
- [x] Media Playback — 4K/HDR playback, resume sync, auto-discovery (mDNS)
- [ ] Media Detail Page — metadata, episodes, actions, file info (in-flight: feature_flutter_media_detail)

## Deferred to Post-v1.0

- [ ] Import List UI Test Coverage — cut to post-v1.0; low runtime risk, deferred per 2026-06-07 scope review
- [ ] Frontend Component Test Coverage Gaps — cut to post-v1.0; merge candidate with MSW coverage into one post-v1.0 frontend-testing track
- [ ] Server Service Test Coverage (remainder: 6 of 10 services) — cut to post-v1.0; runtime-critical 4 services scoped in v1.0, remainder deferred per 2026-06-07 scope review

---

**Sign-off:** v1.0 scope ratified by maintainer on 2026-06-07. The above checklist defines the v1.0 boundary. All `[x]` capabilities are demonstrably built and integration-tested at HEAD. The two `[ ]` items under Capabilities are the only in-flight feature tracks (`feature_flutter_media_detail`, `feature_scheduler_automation_dashboard`); they must either ship in v1.0 or be consciously cut before the tag. All other deferred work is enumerated under Deferred to Post-v1.0 and parked behind the release line.
